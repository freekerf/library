# Evidências de teste

Fotos de grades de teste que sustentam receitas `tested`. Organize por material:

```
evidence/<material-id>/<recipe-id>-<autor>.jpg
```

Referencie o arquivo em `confidence.evidence` (caminho relativo à raiz do
repositório) ou use um link `https://`. A validação falha se o arquivo não existir.
Prefira JPEG ≤ 500 KB.
